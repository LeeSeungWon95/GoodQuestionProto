# 굿퀘스천 — 결정 기록 및 위험 기록

|---|---|---|---|

| D-08 | 추천 이야기는 **로직 미구현, 고정 데이터로 UI 영역만 배치** | MVP 요건 문서에 명시된 사항 | 확정 (요건 문서 근거) |
| D-09 | 소셜 로그인은 **Supabase Auth 제공자 1개 우선** (구글 권장) + 이메일 가입 | 요건은 "카카오·구글·네이버 중 1개 이상". Supabase Auth는 구글 기본 지원(카카오는 커스텀 OAuth 필요) | 제안 — 팀 확인 필요 |
