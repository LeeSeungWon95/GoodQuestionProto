# 굿퀘스천 — UX/UI 가이드라인 (고객 인터뷰 근거)

> 근거: 「굿퀘스천_고객인터뷰_UXUI_참고사항」 — 실제 아동·보호자 인터뷰/테스트에서 확인된 사항.

## 핵심 원칙

> 저학년 아동이 **화면을 해석하는 데 힘을 쓰지 않고**, 캐릭터의 말을 듣고 자신의 생각을 말하는 데 집중할 수 있어야 한다.
> 화면 구성보다 **대화 순서·현재 상태·다음 행동**이 명확하게 인지되는지가 중요하다.
> 캐릭터는 안내자가 아니라 **실제 대화 상대**처럼 느껴져야 재발화와 몰입을 이끈다.

## MVP 디자인 체크리스트

| 항목 | 지침 | 구현 반영 |
|---|---|---|
| 텍스트·정보량 | 긴 텍스트, 작은 글씨, 복잡한 구성 금지 | 큰 글씨, 화면당 정보 최소화 |
| 콘텐츠 제시 | 긴 설명은 한 문장씩 단계적으로 제시 | 도입·전개 내레이션 문장 순차 표시 |
| 화면 집중도 | 정보가 많으면 "지금 뭘 해야 하는지"를 놓침 | 현재 단계 요소만 활성 표시 |
| 말하기 타이밍 | 아이가 말할 시점을 시각·청각으로 명확히 안내 | 캐릭터 발화 종료 → 효과음 + 마이크 활성 연출 (MVP 요건과 일치) |
| 진행 상태 | 발화 중 / 변환 중 / 응답 대기 상태를 분명히 구분 | 상태별 UI (녹음 애니메이션, 변환 스피너, 캐릭터 생각 중) |
| STT 확인 | 자기 말이 제대로 입력됐는지 확인 가능해야 함 | STT 결과 화면 표시 후 보내기 (MVP 요건과 일치) |
| 음성 재생 | 매번 수동 재생보다 자동 재생이 적합 | 자동 재생 + 다시 듣기 버튼 (iPad 제스처 제약은 R-09 참고) |
| 조작 복잡도 | 버튼·기능 동시 노출 시 어려움 | 단계당 핵심 버튼 1개 원칙 |

## 추후 콘텐츠·기능 참고 (설계 시 고려)

| 항목 | 확인된 사항 | 반영 지점 |
|---|---|---|
| 대화 상대성 | 캐릭터가 바로 동의하지 않고 입장을 유지할 때 아이가 다시 생각·설명함 | 캐릭터 LLM 프롬프트: disagreement 반응 원칙(무조건 부정하지 않되 걱정 하나 제시) — 대화작동규칙과 일치 |
| 힌트 제공 | 답하기 어려운 아동에게 상황 단서·간단한 힌트 필요 | GUIDED 모드·soft-cue가 이 역할. 정답을 주지 않고 생각을 시작하게 돕는 수준 |
| 캐릭터 몰입 | 역할극이 몰입에 긍정적. 반응·감정이 대화 흐름 안에서 자연스럽게 | FR-10(캐릭터 마음 변화)의 근거 |
| 난이도 차이 | 아동별 학년·언어 수준 차이가 큼 — 텍스트·질문 난이도 조절 가능성 고려 | `stories.difficulty` 필드 활용 여지. MVP는 단일 난이도 |
| 이야기 재구성 | 장면 순서 맞추기 활동이 이야기 이해에 도움 | FR-07의 근거 |
| 보호자 정보 | **점수·복잡한 분석보다 "아이가 실제로 어떤 말을 했고 무엇을 잘 표현했는지"를 원함** | FR-08 리포트 설계 방향: 대표 발화 + strengths 중심, 점수화 지양 |
